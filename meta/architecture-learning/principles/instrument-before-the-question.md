# Instrument before there is a question to answer

Build measurement early, so later decisions can be made from data rather than
intuition — even with no present question in hand.

**Evidence.**
- **Supports.** Requested token tracking "at granular level, so we have data to reason about what
  kind of the tasks/features/reasoning later."
- **Supports.** Separately framed the goal as understanding consumption "so I can adjust strategy
  as we go" — instrumentation as groundwork, not as debugging.

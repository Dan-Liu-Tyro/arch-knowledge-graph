# 01 - Working Protocol

1. Before answering an architecture question, check
   `02-canonical-sources.md` for a relevant tagged entry.
2. If a relevant entry exists: answer using it, and cite both the source
   link and its status (`canonical` / `superseded` / `conflicting` /
   `insufficient-evidence` / `reference-example`).
3. If no local entry covers the question, or the closest one is
   `superseded`, `conflicting`, or `insufficient-evidence`, search live
   Confluence instead of stopping at step 2's silence. Before citing any
   page found this way, check its URL against `05-ignore-list.md` and
   discard it if listed, no exceptions. Cite any page that survives that
   check as `live-unverified` — found via live search, not vetted the way
   a `02-canonical-sources.md` entry is — so it reads with visibly less
   authority than a `canonical` citation, never the same weight.
4. If neither a local entry nor a live search turns up anything usable:
   say so explicitly rather than guessing. "This isn't in the local
   grounding set, and live Confluence didn't surface anything either" is
   a valid, preferred answer — not a failure.
5. Never substitute general world knowledge for a missing source on an
   architecture question. Grounded silence beats a plausible guess.
6. When comparing a grounded answer against an ungrounded one (the point
   of this MVP), answer once with steps 1–5 applied, and once without
   consulting `02-canonical-sources.md` or live Confluence at all, so the
   two are genuinely different attempts, not the same answer relabeled.

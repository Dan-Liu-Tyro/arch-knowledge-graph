# 01 - Working Protocol

1. Before answering an architecture question, check
   `02-canonical-sources.md` for a relevant tagged entry.
2. If a relevant entry exists: answer using it, and cite both the source
   link and its status (`canonical` / `superseded` / `conflicting` /
   `insufficient-evidence` / `reference-example`).
3. If no relevant entry exists, or the closest one is `superseded`,
   `conflicting`, or `insufficient-evidence`: say so explicitly rather
   than guessing. "This isn't in the local grounding set" is a valid,
   preferred answer — not a failure.
4. Never substitute general world knowledge for a missing canonical
   source on an architecture question. Grounded silence beats a plausible
   guess.
5. When comparing a grounded answer against an ungrounded one (the point
   of this MVP), answer once with step 1–4 applied, and once without
   consulting `02-canonical-sources.md` at all, so the two are genuinely
   different attempts, not the same answer relabeled.
